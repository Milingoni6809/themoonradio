# Chigs FM — Android Wrapper

This project wraps the web app at **https://chig-fm.vercel.app/** into a native Android application using a WebView.

## Option 1: Build APK / AAB in the Cloud (No Android Studio Needed)

This project includes a **GitHub Actions workflow** that builds the APK and AAB automatically — no Android Studio or local SDK required.

### Steps
1. Create a free GitHub account at [github.com](https://github.com) if you don't have one.
2. Create a **new empty repository** (don't add a README or .gitignore — keep it empty).
3. Extract this ZIP and push the files to your new repository:
   ```bash
   git init
   git add .
   git commit -m "Initial Android project"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
4. Go to your repository on GitHub and click the **Actions** tab.
5. You'll see a workflow called **Build APK & AAB** — it runs automatically on every push.
6. Wait ~5 minutes for the build to finish (green checkmark).
7. Click on the completed workflow run, then scroll down to **Artifacts**.
8. Download:
   - **app-debug.apk** — installable APK for testing on any Android device
   - **app-release.aab** — AAB bundle for uploading to Google Play Store

That's it! You get a ready-to-install APK and a Play Store-ready AAB without installing any software.

## Option 2: Build Locally with Android Studio

### Prerequisites
- Android Studio (Hedgehog or newer)
- JDK 17
- Android SDK (compileSdk 34)

### Build APK (for installation/testing)
```bash
./gradlew assembleDebug
```
Output: `app/build/outputs/apk/debug/app-debug.apk`

### Build AAB (for Play Store upload)
```bash
./gradlew bundleRelease
```
Output: `app/build/outputs/bundle/release/app-release.aab`

### Build Signed Release APK
```bash
./gradlew assembleRelease
```

## Signing the Release Build (for Play Store)
Create a keystore:
```bash
keytool -genkey -v -keystore release.keystore -alias mykey -keyalg RSA -keysize 2048 -validity 10000
```

Add to `app/build.gradle` inside `android {}`:
```gradle
signingConfigs {
    release {
        storeFile file('../release.keystore')
        storePassword 'YOUR_PASSWORD'
        keyAlias 'mykey'
        keyPassword 'YOUR_PASSWORD'
    }
}
```
Then set `signingConfig signingConfigs.release` in the `release` build type.
